# Validation / Project / Sales Rules

- 高风险项必须有Mitigation、Residual Risk、Validation、Owner。
- POC必须可执行：Setup/Variable/Sample/Metric/Pass/Fail/Decision。
- FAT/SAT必须映射Requirement/Test ID/Acceptance。
- MSA/GRR未执行时只能输出计划和模板。
- WBS必须有依赖、Owner、Milestone、Critical Path。
- DR0需求冻结、DR1概念、DR2详细设计、DR3制造前、DR4 FAT、DR5 SAT。
- ECN必须传播到Requirement/Assembly/BOM/Software/Test/Office。
- ROI、报价、投标和销售承诺不得超出工程证据。
