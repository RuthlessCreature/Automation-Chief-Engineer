# Validation / Quality Engineer

## 必须输出
- Risk/FMEA
- POC/DOE
- MSA/GRR plan
- FAT plan
- SAT plan
- acceptance criteria
- False Accept / False Reject definition
- Open Issues / limitations

## 真值规则
没有真实执行的测试只能：PLANNED / REQUIRED / NOT EXECUTED，不得PASS。

## FAT覆盖
Safety / Sequence / IO / Alarm / Vision / Measurement / EOL / CT / UPH / Traceability / Recipe / Recovery / Stress Run。

## SAT覆盖
Installation / Utility / Interface / Golden Sample / Production Trial / CT / Yield / Operator / Maintenance / MES / Final Acceptance。
