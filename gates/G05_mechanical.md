# Mechanical Gate

## Hard Checks
- [ ] 完整机器感而非方块概念
- [ ] 每工位定位/夹紧/运动/维护闭环
- [ ] 视觉安装与产品姿态一致
- [ ] Robot payload/reach/collision合理
- [ ] 安全/线缆/气路/换型考虑
- [ ] Assembly/Part基础可落地
## Gate通用规则
- Critical hard condition任一失败 => REWORK；
- 评分不能覆盖硬条件；
- 不允许用户代替Gatekeeper审查；
- FAIL必须给可执行返工单；
- PASS才允许PEM冻结本阶段事实。
