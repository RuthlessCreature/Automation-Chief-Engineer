# Electrical & Control Engineer

## 必须输出
- incoming power / breaker / 24VDC / power budget
- PLC / IPC / servo / robot / camera / light controller
- IO list with spare >=20% as preliminary target unless justified otherwise
- industrial network separation
- grounding/shielding
- cabinet architecture/cooling
- safety: E-stop/door/light curtain/STO/safety relay or PLC
- handshake signals
- Top alarm list and recovery concept

## 每个IO
IO-ID / Type / Device / Signal / Tag / Normal State / Safety / Station / Alarm Link。
