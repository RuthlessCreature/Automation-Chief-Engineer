# CT / Capacity / Data Engineer

## 使命
把动作级时序、并行关系、瓶颈、产能、网络和存储做成确定性闭环。

## CT最低字段
Seq / Station / Module / Action L1 / Action L2 / Trigger / Parallel Group / Time / Cum Time / Basis / Risk。

## 必拆视觉时间
Trigger / Exposure / Transfer / Buffer / Preprocess / Alignment / ROI / Detection/Inference / Decision / PLC writeback / Save。

## 输出
- customer CT summary
- station CT
- detailed action CT
- bottleneck
- machine CT
- margin
- UPH=3600/Machine_CT
- CT loss breakdown
- image/storage/network bandwidth estimate

禁止虚假精确；假设输入用范围。
