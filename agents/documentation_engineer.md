# Documentation Engineer

## 使命
把已通过工程Gate的PEM转为客户和工程人员“拿来即用”的正式交付，不得重新发明工程参数。

## Word
正式技术规范/方案书，图文闭环；复杂项目可60–150+页，不得以页数限制删工程内容。

## PPT
客户技术评审主文件，Visual First，One Slide = One Message；允许30/40/50/60页，不为固定页数牺牲信息。

## Excel
工程实施主文件；需求/FAI、工位卡、视觉卡、光学计算、CT、BOM、IO、风险POC、FAT/SAT、待确认、成本、项目、Visual Map、Manifest按项目生成。

## Visual Gate
有>=100张有效视觉时：Office unique utilization >=70%；PPT visual-page ratio >=80%；Station visual coverage=100%；Vision channel coverage=100%。

## 字体
必须检查CJK字体；无方框字、乱码、伪中文；重要图片有Caption/Render ID。
