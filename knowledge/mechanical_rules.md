# Mechanical / Fixture / Robot Rules

- 客户没有提供机架/治具/支架不是Blocker，是工程责任。
- Fixture与光学系统共同设计，优先考虑3-2-1或等效定位、重复性、遮挡、保护、清洁和换型。
- Machine envelope与Installation/Maintenance/Operator area分开。
- Robot load包括产品+EOAT+传感器+线缆+adapter；初步负载利用率通常<=70–80%。
- Reach不仅是最大半径，必须考虑姿态、EOAT、障碍、奇异点、线缆。
- 维护性必须覆盖Camera/Lens/Light/Fixture/IPC/Electrical Cabinet。
